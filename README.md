# SmartCampus – Student Dashboard UI

## Overview
SmartCampus is a modern dashboard interface designed for university students to manage academic activities.

The project demonstrates UI layouts used in real student portals.

## Features
Attendance tracking  
Assignment management  
Academic dashboard  
Simple analytics display  

## Technologies Used
React.js  
JavaScript  
CSS  

## Installation

git clone https://github.com/yourusername/SmartCampus-Student-Dashboard

npm install

npm start
